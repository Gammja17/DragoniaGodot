# Dragonia (Godot)

브라우저판 [Dragonia](https://github.com/Gammja17/Dragonia)를 Godot 4 로 옮기는 저장소.
게임 내용(이야기·수치·지도·그림)은 그대로 두고 엔진만 바꾼다.

- 엔진: Godot 4.7 (Steam판), 렌더러는 웹·모바일에서 다 도는 Compatibility
- 기준 원본: Dragonia `154b06d` (이식이 끝날 때까지 2D판은 동결)
- 내보내기: 웹(GitHub Pages) + 안드로이드 APK + PC

## 폴더

| 폴더 | 내용 |
|---|---|
| `scenes/` | 씬. UI 도 코드로 만들지 않고 씬으로 만든다 |
| `scripts/` | GDScript. 2D판 `src/` 와 같은 갈래(core·world·render·entities…)로 나눈다 |
| `data/` | 2D판 `src/data` 를 JSON 으로 옮긴 것 (손으로 고치지 않는다). 데이터 속 함수는 `scripts/data/conditions.gd` 에 GDScript 로 옮기고 경로("모듈:경로")로 이어 붙인다 |
| `assets/` | 2D판 에셋 복사본 (출처는 `CREDITS.md`) |
| `tools/` | 변환·검증 도구 |
| `_ref2d/` | 2D판 원본 사본. git 에 넣지 않는다 (아래 참고) |

## 2D판 원본 사본 만들기

`tools/export_data.mjs` 와 대조 검사가 읽는다.

```bash
mkdir _ref2d && git -C ../Dragonia archive 154b06d | tar -x -C _ref2d
echo '{"type":"module"}' > _ref2d/package.json
node tools/export_data.mjs
```

## 검증 도구

- `tools/dump_maps.tscn` — 지도를 구워 행별 해시를 뽑는다. 브라우저에서 2D판으로 같은 해시를 뽑아 대조한다
  (1단계에서 VILLAGE·LAKE·FALLS·SKY_RUINS·SNOW_ROAD·DOJO 모두 픽셀 단위로 같았다)
- `tools/test_move.tscn` — 걷기·대시·물가 충돌
- `tools/dump_world.tscn` — 지도를 채운 결과(소품 종류별 수, 마을 용 자리). 2D판 `__dragonia.state.entities` 와 대조
- `tools/test_travel.tscn` — 포탈로 지도 오가기, 이야기가 안 열어 준 길 막기
- `tools/shot.tscn` — 원하는 지도에서 화면 찍기 (`--write-movie`)
- `tools/test_combat.tscn` — 숲길에서 슬라임을 겨눠 쏘기, 잡기·경험치·떨어진 것, 맞기
- `tools/test_boss.tscn -- MORGATH_LAIR` — 보스가 깨어나 패턴을 쓰고, 쓰러지면 숨결·기술·유물을 주는지
- `tools/test_raid.tscn` — 사냥꾼 습격, 마을 용의 반격, 기술 쓰기
- `tools/test_story.tscn` — 새 판을 처음부터: 프롤로그 → 촌장 → 포코의 마을 구경 → 마을 용 대화 → 게시판·석비 → 굴·둥지·잠 → 알·아이 → 굴 탐험 → 저장
- `tools/test_load.tscn` — test_story 가 남긴 세이브를 불러 이어 하는지
- `tools/parse_all.tscn` — 모든 스크립트를 불러 문법·형 오류를 드러낸다 (Godot 는 쓰는 스크립트만 컴파일한다)
- `tools/test_hud.tscn` — HUD 판이 뜬 뒤에도 클릭이 세상에 닿는지, 판 위 클릭은 막히는지, 추적창·[U]
- `tools/test_title.tscn` — 처음 화면 → 새 용(2번 칸) → 게임 → 처음 화면으로 → 이어 하기 → 지우기
- `tools/test_journal.tscn` — 일지 탭 열 개, 성장 마디 찍기 · 스킬 장착과 강화 · 유물 · 퀘스트 추적
- `tools/test_touch.tscn` — 터치: 스틱 · [불] 유도 숨결 · 용 탭하면 말 걸기 · 칩, 가족 창 · 굴 꾸미기 판
- `tools/test_fx.tscn` — 조명(낮·새벽·밤·폭우·붉은 달·굴 속의 어둠, 광원 모으기) · 날씨 그림 · 화면 효과 판([L], 손잡이 저장, 되돌리기, 연 채로 세상 클릭)
- `tools/shot_ui.tscn -- title` — 처음 화면·새 용·설정·도움말 찍기 (`title` · `create` · `settings` · `help`)
- `tools/shot_talk.tscn -- hub` — 말 걸기·안내·굴 화면 찍기 (`hub` · `tip` · `den` · `cave`)

```bash
godot --headless --path . tools/test_move.tscn
```

## 진행

1. **뼈대** — 데이터 변환, 입력, 카메라, 지형 생성, 충돌, 용 걷기 ✅
2. **월드** — 소품·나무, 포탈과 지도 이동, 장(章)이 여는 길, 마을 용 배치(일과)·어슬렁거림·혼잣말, 이름표, 지역 배너·알림 ✅
3. **전투** — 숨결·조준·치명타·속성 연계, 적 18종과 AI(예고→발동→숨 고르기), 정예 접사, 무리 출현, 기세·간발·물어뜯기, 떨어진 것, 타격감, 스킬 20종·필살기, 바닥 장판, 보스 5, 사냥꾼 습격과 마을 용의 반격, 유물 얻기 ✅
   (베르단의 포위·수련장 시험 표지는 이야기·대화창과 함께 4단계로)
4. **시스템** — 대화창·말 걸기·마을 용의 고유 메뉴(선물·대련·술래잡기·대장간·축복), 퀘스트, 이야기(수련·승급 시험·의식·아침 장면·밤의 사건 41), 컷씬·프롤로그·마을 구경,
   하루 시계·날씨·밤 이벤트·일과대로 걸어 다니기·잡담, 세이브(user://), 이동 석비, 게시판 잡일, 굴 탐험(미궁 생성), 베르단의 포위, 수련장 시험 표지,
   보금자리 굴·둥지·살림살이, 연애(질투·다툼·헤어짐·언약), 가족(알·아이·성년식·나들이), 스승의 하루 일과, 길잡이(화살표·자동 이동) ✅
   (굴 꾸미기 판은 지금 대화창에 띄운다. 그림 목록이 달린 제 판은 5단계에서)
5. **UI** — HUD, 처음 화면·세이브 칸 셋·새 용, 설정·도움말, 일지(성장·스킬 나무), 가족 창, 굴 꾸미기 판, 터치 조작(스틱·단추·유도 숨결·탭 말 걸기), 작은 화면 맞춤 ✅
   (시험 장면은 9번 칸을 쓴다. 사람이 쓰는 1~3번 칸은 건드리지 않는다.
   시험은 모두 `--headless` 로 돌린다. 창을 띄우는 화면 찍기(shot_*)는 따로 부탁받았을 때만)
6. **연출** — 조명(빛 지도 · 광원 · 스스로 빛나는 것 · 반딧불이 · 구름 그림자), 낮밤, 날씨 그림(비 · 눈 · 불티 · 재 · 번갯불), 후처리(번짐 · 색 어긋남 · 피격 일렁임 · 가장자리 어둠 · 색 보정), 화면 효과 판 ✅ · 소리

## 화면 효과 판 쓰는 법

게임 안에서 **[L]** 을 누르거나, **[Esc] → 설정 → 화면 효과 [조절하기]** 로 연다.
판은 화면 오른쪽에 붙고 뒤를 어둡게 가리지 않는다. 연 채로 걸어 다니고 싸우면서 손잡이를 끌면 바로 화면에 나타난다.
고친 값은 이 기기의 `user://settings.cfg` 의 `[fx]` 에 남는다 (세이브 칸과 상관없다). **[처음 값으로 되돌리기]** 로 원래대로.

| 줄 | 하는 일 | 처음 값 |
|---|---|---|
| 후처리 전체 | 아래 번짐~채도를 한꺼번에 켜고 끈다. 느린 기기라면 끄면 가벼워진다 | 켜짐 |
| 빛 번짐 | 불길·번개처럼 밝은 것이 둘레로 번지는 세기 (0~200%) | 85% |
| 번짐 문턱 | 이 밝기보다 밝은 곳만 번진다. 낮출수록 온 화면이 뿌옇게 빛난다 | 62% |
| 색 어긋남 | 가장자리에서 빨강·파랑이 살짝 벌어지는 렌즈 느낌 | 100% |
| 피격 일렁임 | 맞은 순간 화면이 물결치는 세기. 어지러우면 0% | 100% |
| 가장자리 어둠 | 화면 귀퉁이를 어둡게 눌러 가운데로 눈이 가게 한다 | 100% |
| 밝기 · 대비 · 채도 | 화면 전체의 색 보정. 채도 0% 는 흑백 | 100% |
| 밤의 어둠 | 밤·굴 속이 어두워지는 정도. 0% 면 늘 낮처럼 밝다 | 100% |
| 구름 그림자 · 반딧불이 | 낮의 구름 그림자와 밤의 반딧불이 | 켜짐 |
| 비 · 눈 · 불티 | 날씨 그림. 꺼도 날씨의 효과(숨결 세기)는 그대로 | 켜짐 |

만드는 쪽에서 처음 값을 바꾸려면 `scripts/render/screen_fx.gd` 의 `DEFAULTS` 를 고친다.
층 순서: 세상(0) → 조명(1, `render/lighting.gd`) → 날씨(2, `render/weather_view.gd`) → 후처리(3, `render/post_fx.gd` + `assets/shaders/postfx.gdshader`) → 피격 번쩍임(4) → 이름표(5) → 컷씬(6) → HUD
