# 미뤄 둔 것: HUD 세션 파일에 걸린 화면 글

대사 검수와 용어 통일 때 고치려던 것인데, 다른 세션("화면 알림 정리", 원래 폴더의 improve/depth-flow 브랜치)이 같은 파일을 고치는 중이라 손대지 않았다.
그 세션이 커밋하고 improve/story-depth에 합쳐진 뒤에 한 번에 넣는다. 파일: hud.gd · hud.tscn · dragon.gd · vfx.gd · dialogue.gd.

## 1. scripts/entities/dragon.gd:350

- 지금: 날아오른다. 같은 키로 내려앉는다.
- 고칠 글: 날아오른다. [Z]로 다시 내려앉는다.
- 까닭: 어느 키인지 없다. [Z]로 쓰면 GameInput.words 가 패드 [L3]·터치 [비행]으로 바꿔 준다.

## 2. scripts/entities/dragon.gd:390

- 지금: 새 숨결 [%s] 획득! %s ([%s]번 키)
- 고칠 글: 새 속성 [%s] 획득! %s (숫자 [%s] 키로 바꾼다)
- 까닭: '([2]번 키)'는 무엇을 하는 키인지 없다. 숫자는 GameInput.words 가 바꾸지 못해 터치([속성] 단추)·패드(십자 ←→)에서는 없는 키를 가리킨다. KEY_WORDS 에 숫자 키를 더하거나 기기별 문구를 둔다.

## 3. scripts/entities/dragon.gd:394

- 지금: 품은 숨결이 셋이 되었다. 적을 맞혀 게이지를 채우면 [X]로 융합 브레스를 쓸 수 있다.
- 고칠 글: 속성이 셋이 되었다. 적을 맞혀 필살기 게이지를 채우면 [X]로 융합 브레스를 쓸 수 있다.
- 까닭: 게임은 이것을 '숨결'이라 부르는데(숨결: 화염, 새 숨결 획득, 세 숨결) 여기·skill_slot.gd:44·성장 나무·유물·대장간 효과만 '브레스'다. 필살기 이름도 '융합 브레스'(여기)·'삼원 융합 브레스'(elements.json)·'필살기'(도움말)로 섞여 있었다. 용어 표대로 '속성'과 '융합 브레스'로 맞춘다.
